# モリベユリ（@yuri_insta_oni）コンテンツ・リサーチ

調査: 2026-10-27。Instagram投稿120件（キャプション）と、直近リール4本の内容分析（media-understanding）に基づく。

## アカウントの骨格
- 表示名「モリベ ユリ/インスタリールの鬼👹」、フォロワー約5.7万、ビジネスアカウント
- ポジション：「あなただから」で選ばれるトークリール発信。埋もれる発信を卒業し「ほしい！」が作れるインスタへ
- 商品：教材「トークリールの教科書」（受講2,000人）、インスタ集客講座「storygram lab」主宰
- 本人は福岡在住・1987年生まれ・シングルマザー（ブログ「わがままシングルマザー！」wagamom.com のプロフィール）。情報発信業・ライター・コーチング
- アカウントは垢BANで3代目。発信歴と継続そのものが実績の語り口になっている

## リールの内容（サンプル4本の実査）
1. **自覚の3分類と「伝わる言葉」**（いいね410）
   - アダルトチルドレン／モラハラ／毒親は自分の業界では「禁止ワード」と紹介
   - 人は自覚の度合いで3種に分かれる：①すでに行動した人 ②知っているが動けない人 ③自覚がない人
   - 自覚がない人に「モラハラ」のようなバズワードは届かない。具体的な行動で描く（例：玄関のドアの音で夫の機嫌をうかがう）ことが必要、という主張。自覚のない人への伝え方の無料特典へ誘導
2. **「強い人」なんていない**（いいね1,355・サンプル内最多）
   - 「情報発信が強い人」というラベルを本人が否定。メンタルも体力も弱く、文章も論理も苦手、副業で100万円超の損失、シングルマザーで片手に赤ちゃんを抱えて入力していた等の自己開示
   - 結論：強い人がいるのではなく、弱くても続けた人が「強い」と呼ばれる。弱さの開示と継続がテーマ
3. **伸びないリールの添削型解説**（いいね542）
   - ダイエットリールを題材に「選ばれない発信」の3つの過ち：結果だけ言う（3ヶ月で5kg）、つなぎ言葉がぼんやり（歩けばいい等）、過程のストーリーがない
   - 産後太り→好きなジーンズが入らない→自信喪失、という感情の過程を描くことが必要、という言語化の指導
4. **一人二役の相談コント**（いいね567）
   - クライアント役（シングルマザー、ダイエットと離婚を発信、1万フォロワーと収益化が目標だがサービス告知でリーチが落ちるのが不安）×コーチ役
   - 教えは「質問の仕方」：道を聞くときはまず目的地を言う。具体的なゴール→補足情報の順

## 柱の整理
- **発信ノウハウ**（言語化、ストーリー化、質問の設計、選ばれる発信）が商品に直結する本柱
- **女性の心理・関係性**（モラハラ、自覚の有無、夫婦関係、弱さ）が共感層。リールの素材として頻繁に使われる
- **本人の物語**（シングルマザー、弱さ、失敗、継続、実績）が信頼の担保
- 受け手は「発信で仕事を作りたい主婦・ママ層」が中心と読める（卒業生の成果報告も主婦層が目立つ）

## NO3の話との接点（調査所見）
- ユーザーの言う「女性がやりがちなこと／ママ系の心理」は実際にリールの素材になっている。特に「自覚の3分類」は、先にユーザーが言語化した「アイダ層＝自覚がある人／ママ層＝自覚がない」というセグメント論と同型
- 手法も一致：「ラベル（モラハラ等）は自覚のない人に届かない。具体的な行動・場面で描く」＝フラの「感情ラベルを貼らない、場面で見せる」と同じ原理を、森部さんは発信指導の言葉で語っている

## 再リサーチ 2026-10-29（NO3 依頼）

確認時点: フォロワー56,743、投稿807件。プロフィールは「埋もれる発信で大丈夫？／刺さる起業家 続出／『ほしい！』が作れる発信／『あなただから』で選ばれる人に／2,000人受講中『トークリールの教科書』／storygram lab主宰／5大特典→公式LINE」。

### 投稿の実態

### 直近リール8本の内容分析
1. **一人二役・過去の自分×現在の自分**（4,761）: 2016年の自分（1歳児・ワンオペ・収入なし・離婚を考えていた）が愚痴り、2026年の自分（フォロワー5万・教材2,000人）が答える。本人の物語そのものを教材化
2. **コメント返し＋弱さの開示**（1,424）: 「強い発信者」というラベルに反論し、副業で100万円超の損失、体力・文章・論理の弱さを列挙。「弱くても続けた人が強いと呼ばれる」
3. **DM事例の読み解き**（1,305）: 一見丁寧な「福岡で会いたいです」というDMの裏にある配慮のなさを指摘し、発信者としての考え方を教える
4. **観察→原則化**（1,251）: 同業者が発信をやめて消える現象から「続けた人が残る」という原則へ。メイクをしながら語る日常トーク形式
5. **コメント返し＋販売心理**（1,043）: 「1万円払ったらいつ回収できる？」への返答で、価格を先に出さない・価値が先という販売の順序を教える。価格は公式LINE登録後に開示、という自社の導線も説明に含む
6. **一人二役・提供者×産後ママ**（308、最新）: 高単価の寝かしつけ支援サービスを題材に、ママ側の懸念（寝不足で予定が組めない、すっぴんで画面に出られない、価格）を一つずつ受けて解消する受け答えの教材
7. **三層セグメントの講義**（460）: 自覚の3分類と、③にはラベルでなく場面（玄関のドアの音で夫の機嫌をうかがう）で描く、という既出の核テーマ
8. **ジャンル別の受け手心理**（689）: 子育てコンサルを題材に、ママは「自分で解決すべき」と考えて対価を払いにくい、論理ではなく感情の接続が要る、という指導

### 構成の型（所見）
- 入口は常に具体的な場面・事例（コメント、DM、過去の自分、ママの台詞、他社の消えた発信者）
- 中で、その場面に隠れた心理や思い込みを言語化して「気づかせる」
- 出口は、発信・販売の原則として一般化する。一部は特典・LINEへの接続で締める
- 狭い意味の「他人のリール添削」は前回確認分（ダイエットリールの添削型解説）で、直近は「事例の添削」＝コメント・DM・相談の受け答えのズレを指摘して直し方を示す形が中心
- 二重構造: 教える相手は「ママ向けに発信する人」で、題材は「ママの心理」。ママ層への教育が、ママの日常の場面を経由して行われる

### 「トークリールの教科書」の中身の逆算（発信からの推定。実物未確認）
1. トークリールの形式（一人二役、コメント返し、日常トーク）
2. 受け手の自覚の3層と言葉の出し分け（ラベルではなく場面で描く）
3. 場面の作り方（具体的な行動・台詞で受け手の日常を再現する）
4. 事例の読み解き（コメント・DM・相談から、相手が気づいていない心理を言語化する）
5. 自己開示の設計（弱さ・失敗・自分の物語を信頼に変える）
6. 販売の心理（価値→価格の順序、価格の出し方、高単価への懸念の解消）
7. 継続の設計（やめる人が多い前提で、残る側に立つ）
8. ジャンル別の受け手心理（子育て等、ジャンルごとに「払わない理由」が違う）

## 深掘り 2026-10-29（NO3 の観点: 顧客の心理構造と三層の具体）

追加サンプル8本（累計16本）からの整理。森部さんの顧客は「発信でビジネスをやりたい人」で、彼女の教育の核は「その人たちが、自分のターゲットの心理・状態を分かっていない」ことの解消にある、という NO3 の読みを、実物で検証した。

### 森部さんの顧客（発信者）の「分かっていない」具体
彼女のリールに繰り返し出る、発信者側のズレ:
- プロフィールに情報を詰め込む（地名や誰でも書く文句を入れる）。ジャンル認知と自己紹介の設計がない（添削事例: 再生18万・フォロワー200の発信者を、プロフィール文の組み替えで5,000まで伸ばした話）
- 価格を先に提示して売り逃す。価値→価格の順序が逆
- 買う側になると「1万円払ったらいつ回収できる？」と保証を求める。事前資料を読まない。他の先生の助言を判断なしにコピーする（＝講座の受講をお断りする3条件として本人も提示）
- 「浅い発信者」: 相撲を見て「迫力があった」としか言えない。観察を自分の五感と体験に接続できていない

### 三層の具体像（リールに登場する人物からの抽出）
- **③自覚がない**: 2016年の森部本人（1歳児・ワンオペ・収入なし・「夫が変わってくれたら」と他者が変わるのを待つ）。一人二役の産後ママ（出てくる言葉は寝不足・すっぴん・予定が組めない、という生活の困りごとだけ）。「福岡で会いたいです」と悪気なくDMするフォロワー（自分の要求の重さに無自覚）。届く形は、ラベルや概念ではなく場面と台詞そのもの。一人二役で「演じて見せる」が主手法
- **②知っているけど動けない**: 「自分は弱いから無理」と思っている発信者（メンタル・体力・文章・論理の弱さ）。声の低さ等、自分の特性を欠点だと思っている人。保証がないと申し込めない人。届く形は、森部自身の弱さと失敗の開示＋「弱くても続けた人が強いと呼ばれる」という再解釈＋具体的な言い換え練習（コメント欄で実際に書かせる）
- **①すでに行動した**: 受講生、同業者、添削で伸びた発信者。届く形は原則と概念（ジャンル認知、名前の設計、価格提示の順序、受講をお断りする基準）で足りる

### 「気づかせ」の手順（型として抽出）
場面を演じる／実例を出す → 本人が言いそうな台詞をそのまま出す → 裏にある心理・思い込みを言語化する → 発信・販売の原則に一般化する。
この手順は、③（場面だけ届く）から②（持ち帰れる1点）への橋渡しとして機能している。

### フラ／アイダの発信への逆用（NO3 の狙いに対する所見）
- 森部さんのリールは、③の人の台詞・行動の「実物」を大量に含む。フラのママ層向けの場面素材として、そのまま観察対象になる
- 彼女の「気づかせ」手順は、感情翻訳の変換（段階を見て出口の形を変える）を、リールの構成として実装したものと読める
- アイダ層（②〜①）には、②向けの「言い換え練習」型（自分の言葉で書き直させる）と、①向けの原則提示型が対応する
※以上の逆用は Muse の所見であり、確定した設計ではない（想定として保持）

### ③実物リスト（場面素材・発信から確認できたものだけ）
フラのママ層の場面素材として観察できる、③の人の台詞・行動の実物:
- 「夫が変わってくれたら」と、他者が変わるのを待つ（2016年の森部本人。1歳児・ワンオペ・収入なし）
- 玄関のドアの音で夫の機嫌をうかがう（モラハラという言葉は知らない／届かないが、この行動は毎日している）
- 寝不足で予定が組めない、すっぴんで画面に出られない（産後ママ役の台詞。問題の言語化ではなく生活の困りごととして出る）
- 「福岡で会いたいです」「東京・大阪でもイベントを」とDMする（自分の要求の重さと相手の負担に無自覚。悪気はない）
- 子育ては「自分で解決すべきもの」と考え、支援に対価を払わない（子育てジャンルの受け手心理として提示されたもの）

### 接続の方向（2026-10-29 NO3）
多層ペルソナ構造の中で、ママ層の心理分析は、こうした③の台詞・行動の実物から行い、そこからライティングのシナリオと脚本の構成を決めて、自動化につなぐ。ナレッジには実物をそのまま集め、紐づけは使う時に行う（既存の前提どおり）。

## NO3 の整理（2026-10-29）
- 門口さんの「視聴者心理の徹底分析」と森部さんのやり方は、意味としては同じもの。違いはジャンル（売り場）である

# センチメント実地分析：適応障害・過剰適応・抱え込み（2026-10-30）

## やったこと
NO3 の仮説（キーワードは「抱え込み」ではないか）をキーワードに、SNS上の実投稿を検索して集め、センチメント分析のプロンプト（層3：反応と感情の分布を見る）で読んだ。受け入れるだけにしないための検証。
材料：検索2回（「適応障害 しんどい 本音」「過剰適応 自分を消す」「一人で抱え込む 誰にも言えない」「ずっと一人で頑張ってきた」等）で得た投稿のうち、日本語の当事者・支援者の実投稿 約20件。プラットフォーム側の要約経由のものを含む。いいねは公開数。

## 実投稿に繰り返し出た、本人の言葉のクラスタ
1. 言えない：「『疲れた』という言葉が出せなくなった」「夫に対しても『大丈夫』としか言えなかった」（フルタイムで働く母親・適応障害の当事者投稿）。「頼れないのは意地ではなく、迷惑をかけたくないから」（一人で抱える人の頭の中、という図解投稿）。
2. 合わせる・演じる：過剰適応の当事者と支援者の投稿群。「人に合わせすぎる」「相手の顔色を読むのが生存技術だった」「13年間『普通の社員』を演じ続けた」。精神科医の投稿では「礼儀正しく、気を遣える『いい人』ほど」という指摘（いいね160）、「真面目で頑張る人ほど適応障害になりやすい」（カウンセラー投稿、いいね300）。
3. 見えない・分かってもらえない：「適応障害は理解されない。元気そうに見える外側の下に本当のしんどさがある」（いいね380）。「いつも明るく見える人ほど、実は1人で悩み苦しんでいるかもしれない」（手書きメモ投稿、いいね2.5K）。「傷ついた言葉の記憶より、気づいてもらえない・理解されない感覚の方が長く残る」という投稿。

## 反応の構造
- 一番反応が厚いのは、状態を「名指して承認する」型。過剰適応を解説するカウンセラーのカルーセル（いいね1.3K）が最大級だが、中身は解決策の提示ではなく「合わせようとして疲弊する」という状態の言語化＝教育の形をした承認として機能している。
- アドバイスの常套句への反発が実投稿にある。「適応障害は原因から離れれば良くなるよ」という言葉に何度も傷ついた、という当事者の投稿。解決フックは、この層には「分かってもらえなかった」体験として届く。
- 「全部一人で耐えることが強さではない」という引用投稿（いいね930、コメント19）も、助言ではなく状態の肯定として広がっている。

## 判定（NO3 の仮説に対して）
- 「抱え込み」は当たっている。ただし実投稿の構造では、抱え込みは結果（蓄積）の名前で、上流に2つある。①過剰適応（合わせる・演じる・顔色を読む）という振る舞い、②言えなさ（疲れたと言えない、大丈夫としか言えない）。この2つが回るから、抱え込みが溜まる。
- 反応が起きる一番鋭い点は「抱えている」こと自体より「見てもらえない」こと。だから承認の台詞（抱えてきたんだね）が刺さり、助言が刺さらない。助言は行動に届くが、痛みは認識の不在にあるため。
- キーワードの置き方：設計側では「過剰適応 → 言えなさ → 抱え込み → 見てもらえない」の連鎖で持つ。本文に出すのは本人の言葉の場面（大丈夫としか言えない、等）で、適応障害・過剰適応・抱え込みのラベルは本文の説明には使わない（既存の正本どおり）。

## 追記2（2026-10-30 夜）：層ごとのセンチメント設計（メロディーラインに重みづけを重ねたもの）

前提：あおんぼ方式 Meta 版 §2・§6 と変換表どおりに層を分け、各層のメロディーに感情の重み（ウェイト）の置き場を対応させたもの。ペルソナは「過剰適応 → 言えなさ → 抱え込み」。

### ③ 自覚がない
- Aメロの重み：場面の身体感覚だけ（喉、肩、手）。感情は名指ししない。本人の「言えなさ」の圧に重みが乗ったまま始まる。
- 転調：重みが「私だけ」から「見られていた」へ移る。この層のセンチメントの動きは、この1回の移動が全部。言葉の振幅は小さいが、本人の内側では一番大きい。
- Bメロなし：言語化に重みを置かない。言えないままでいることが、この層にとっての安全であり、設計そのもの。
- サビの固定：薄い安堵。固定先はシェア（同じ人への送り直し）。
- 響く点：「言わなくても、分かってくれた」。

### ② 知っているけど動けない
- Aメロの重み：場面＋、口に出る寸前の小さな感情（疲れた、と言いかける）。
- 転調：重みが「自責」から外れる。分かっているのに動けない自分への重さが、責めない目撃で軽くなる。
- Bメロ：この層では裏の感情の開示に一番重みが乗る（本当は休みたい、の側が開く）。
- サビの固定：「自分で選んだ」感覚。持ち帰れる1点は助言ではなく、本人が選ぶ置き方として置く。固定先は保存と診断への移動。
- 響く点：「責められなかった。選んでいいんだ」。

### ① すでに行動した
- Aメロの重み：概念への知的フック（あいだ、循環）。
- 転調：視座の切り替えで、自分の構造が見える。抱え込みの連鎖が自分のこととして腑に落ちる瞬間に重みが動く。
- Bメロ：過去の自分の場面が、構造で読み直される（意味の再配分）。
- サビの固定：世界観との一致感（このままでも循環している）。固定先は本体 note と商品。

### 層を貫く一点
このペルソナに響くセンチメントは、どの層でも「慰め」でも「励まし」でもなく「正確に見られた」こと。グワッと盛り上がる場所は層で違う。③は目撃の瞬間、②は責めが外れる瞬間、①は構造が腑に落ちる瞬間。
