仕事の流れ

① アカウントを作りたい：人間 → ダッシュボード → IP設計担当。リサーチ、ターゲット、IP設計、プロフィール、センチメント分析、制作指示につながる情報を作る。

② 媒体の運用を始めたい：IP設計 → マーケティング戦略 → MUSE／Grok。媒体別の運用ナレッジを使い、運用方針・KPI・制作内容を決める。

③ 最近の進捗を確認したい：ダッシュボード → GitHubの作業履歴・成果物。どこまで進んだか、何が未実施か、次に何をするかを確認する。

④ もっと改善したい：Perplexity／Discord → 議事録 → 実行指示 → 担当AI。会話をタスクに変え、実行結果をGitHubに戻す。

一言で

人間の仕事とAIの実行をつなぐ ― 仕事を始める → 状況を見る → 話し合う → 指示に変える → 実行する → 履歴に残す → 改善する
