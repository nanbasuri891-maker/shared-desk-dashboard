## ツリー

大ゴール：収益化（Addness式ゴール設定ハーネス）
└─ goals/growth-harness/GOAL.md
   ├─ 購買動機の言語化（型：goals/growth-harness/forms/MOTIVE_FORM.md）
   ├─ 施策の生成（センチメントライティング）
   ├─ 実行（MUSE）
   ├─ 反響の格納（results/ と当該フォルダ）
   └─ 分析 → 次の施策へ

基盤ゴール：Addness式ルーティング（自走の回路）
└─ goals/meta-routing/GOAL.md
   ├─ GOAL を置く → Claude が設計を返す → MUSE が実行 → 書き戻し → NO3 が検収
   ├─ 受け口：routing-receiver（定期実行）
   └─ 現状の置き場：goals/meta-routing/CLAUDE_STATE.md
