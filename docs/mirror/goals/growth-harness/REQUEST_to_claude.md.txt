# Claude への依頼（グロースハーネス loop1：設計と照合）

## 対象
同じフォルダの GOAL.md（Addness式ゴール設定ハーネス）。席の確定は LETTER_to_claude.md（goals/meta-routing 内）のとおり。

## 役割の寄せ（NO3 の整理）
購買動機の言語化の型づくりは、Claude ではなく MUSE の役とする。理由：型は実行と反響の実物から作るもので、実物を持つのは MUSE の側だから。MUSE がやった型を覚えて保存し、次回以降も同じ水準を再現できるようにする。
Claude の役は、その型がルールと方向（収益化の軸）に合っているかの照合と、下記2点の設計。

## 依頼
固定の5見出し形式で `RESPONSE_loop1.md` としてこのフォルダに置くこと。

1. **購買動機の言語化の型の、置き場と照合観点の設計**：型そのものは MUSE が実例から作って同じフォルダに置く。Claude は、置き場の決め方と、出来た型を何と照合するか（ルール／方向／実物との一致）を設計すること。型はまだ無いので、照合は型が置かれた後の回でよい。
2. **反響の格納形式**：MUSE が実行した施策の反響（実数字・反応）を、どの項目でこのフォルダに蓄積するか。
3. **収益化の方向を見る数字**：プロフィール移動・診断開始・購入について、取得できるもの／できないものを分けて、判定に使う数字を決めること。取得できないものは「未確認」として書くこと。

## ルール
- 書き込みは ai/ ブランチのみ。main 不可。
- 実行は RESPONSE の muse_tasks 経由のみ。AUDIT は報告専用。
- Claude の環境は claude.ai 前提で設計すること（顧客へのプロンプト配備時の導入確認のため）。Claude Code は将来の選択肢として記録のみ、今は前提にしない。
- 判断が要る点は human_review に寄せること。
