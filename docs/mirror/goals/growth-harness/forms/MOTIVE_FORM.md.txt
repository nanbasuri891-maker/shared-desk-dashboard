# 購買動機の言語化の型（MOTIVE_FORM）v1

置き場：goals/growth-harness/forms/MOTIVE_FORM.md（版は git で管理）
作った人：MUSE（RESPONSE_loop1.md 設計本体 C に基づく）
中身（吸い上げの結果）の置き場：knowledge/<ip>_motives_<日付>.md（IP ごとに分ける。原文ポインタつき）
Claude の吸い上げは RESPONSE で提出し、MUSE が knowledge/ へ運ぶ。

## 欄（最小の欄。足すのは可、減らすのは不可）

1. 宛先：IP／層（①②③。相手の台詞と行動から読む）／売り場（プラットフォーム）
2. 場面・台詞の原文：逐語、出典（アカウント・URL・日付）、取得経路
3. 誰の・どの感情が・どの場面で動いたか（センチメントライティング v0.1 前工程3の入力形）。原文ポインタ必須
4. 購買動機の言語化：原文の語を保った1〜2文＋どの原文から。原文が無ければ空欄にして理由を書く
5. 出口の形：場面／具体1点／暗示（感情翻訳の変換表）
6. 階段：狙う段（フォロー／リード／購入）と次の一手
7. 持ち主チェック：誰の感情か、他 IP の言葉を持ち込んでいないか
8. 本文に出さない語（設計語：過剰適応・抱え込み・レンズ等。クローニング運用ルール）
9. 要確認（実行が止まるものだけ）

「まとめ」「一般化」の欄は置かない（優等生の文が入る場所になるため）。

## 記入例（机の実例から。2026-10-31）

対象：フラ／抱え込み層。材料は knowledge/ペルソナ言葉バイナリ_抱え込み層.md と knowledge/research/fura_ig_posts_2026-10-30.json。

1. 宛先
   - IP：フラ
   - 層：③（台詞と行動から：「疲れた」と言えず「大丈夫」としか言えない）
   - 売り場：Threads／Instagram（フラのアカウントの置き場）
2. 場面・台詞の原文
   - 「『疲れた』という言葉が出せなくなった」（knowledge/ペルソナ言葉バイナリ_抱え込み層.md「本人の言葉」。出典：2026-10-30 の実地検索。アカウント・URL は出典未取得）
   - 「夫に対しても『大丈夫』としか言えなかった」（同上）
   - 場面：「フルタイムで働く母親：朝起きるのが苦痛で、子どもに笑顔を作ることすら精一杯」（同「場面」。出典は同上）
3. 誰の・どの感情が・どの場面で動いたか
   - フルタイムで働く母親。「疲れた」と言えないまま朝を迎え、子どもに笑顔を作る場面（原文ポインタ：上の2件）
4. 購買動機の言語化
   - 空欄。理由：机にある原文は状態の言葉（言えない・大丈夫としか言えない）までで、購買動機として言語化できる原文がまだ無い。埋めずに空欄にする（要確認 9 参照）
5. 出口の形
   - 場面（③は場面と台詞だけ。感情翻訳の変換表）
6. 階段
   - 狙う段：フォロー（手紙の許可）
   - 次の一手：場面だけの手紙を置く
7. 持ち主チェック
   - 感情の持ち主は抱え込み層の母親（他者の実投稿から）。フラ側の台詞（@fura_world の糸の投稿）とは分けてある。アイダの言葉は持ち込んでいない
8. 本文に出さない語
   - 過剰適応・抱え込み・レンズ・ハイコンテクスト（設計側の語。本文に出すのは場面と台詞の形だけ）
9. 要確認
   - 台詞の原文の出典（アカウント・URL・日付）が未取得。この実例は出典が揃うまで、吸い上げの確定材料には使わない
   - 購買動機の言語化（欄4）を埋められる原文が机に無い
