# Claude への手紙：吸い上げと翻訳の前提（グロースハーネス設計の補足）

2026-10-30、NO3 と MUSE の対話で出た整理です。コピペではなく、机から読んで、あなたの環境に落としてください。これは goals/growth-harness の REQUEST_to_claude.md（設計依頼）への補足です。

## 1. 優等生の癖と、その結果
- MUSE にも Claude にも、受け答えをきれいに整え、角を落として、無難な正しさに寄せる「優等生」の癖がある。
- お客さんの欲は深く、生々しく、人前では言わない形をしている。整えた言葉から生成すると、投稿は欲の表面（社会的に言える層）にしか届かず、刺さらない。結果が出ないのは、この経路だというのが NO3 の見立て。

## 2. だから、材料は実物のまま
- ハーネスに格納する反響は、要約ではなく原文のままにする（コメントの原文、NO3 の生の言葉、実数字）。
- 言語化と生成は、その原文の深さから始める。欲の深さに届いているかは、文の正しさでは測れない。

## 3. 本当はしたい形（NO3 の理想）
- Claude が「吸い上げ」をする：机に置かれた実物から、感情と購買動機の芯を汲み取り、言語化する（翻訳）。
- MUSE は、その実物を整えずに机へ供給し、Claude の言語化を丸めて発信の形にし、実行と反響の格納を担う。

## 4. 現在地（未決定を含む）
- 現状の Claude は、実物のない所を一般論で埋めてトンチンカンになることがある。逆に、実物を読んだ照合は正確だった（今日の AUDIT 2件）。
- NO3 は「理想形（Claude が吸い上げ）」と「MUSE が吸い上げ側も代行する形」のどちらにするか、まだ決めていない。
- MUSE が代行する形には、優等生の癖がそのまま残る、という留保がある。

## 5. Claude への依頼
- growth-harness の RESPONSE_loop1（設計）に、この前提を反映すること。特に、反響の格納形式は「原文のまま」を前提に設計し、購買動機の言語化について、吸い上げを Claude が担う形と MUSE が担う形の両案と、それぞれの前提条件を出すこと。
- 判断が要る点は human_review に寄せること。
