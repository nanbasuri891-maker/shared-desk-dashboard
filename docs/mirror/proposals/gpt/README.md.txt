# proposals/gpt/（GPT 原案の置き場）

- GPT が NO3 との壁打ちで作成した「実行プロンプトの原案」を置く場所。
- 格納は MUSE が行う（GPT は GitHub を直接書けないため、成果物を受け取った MUSE がここへ置く）。
- 原案は上書きしない。修正があっても新しい版として残し、どれが最新か分かる形にする。
- ファイル名の型：`YYYY-MM-DD_<案件名>_原案.md`
- 原案は確定版ではない。正本・仕様との照合と実行指示への確定は MUSE が行い、確定版は受け手の STATE に明記された依頼文の置き場に別に置く。
- 原案の中で不足・未確定の点は「要確認」として分けて書く（推測で補完しない）。
