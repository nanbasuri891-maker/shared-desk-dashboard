# COMMON_AGENT_STANDARD.md
## マクロハーネスAI 全エージェント共通規約

### 基本原則
- すべての作業は上位GOALの達成を目的とする。
- 確認済み事実・仮説・未確認事項を区別する。不足情報を勝手に補完しない。
- 人間の承認が必要な作業は、承認前に実行しない。

### 相談と仕様変更の分離
- 人間から相談を受けた場合、まず governance/ISSUES.md に「問題の記述」を記録する。
- 仕様書や正本を書き換える前に、問題の記述と解決の記述を分離する。
- 正本の改訂は、NO3の承認後のみ行う。

### 翻訳層の必須参照
- 概念を手順に変換する場合は、必ず specs/TRANSLATION_LAYER.md（または governance/TRANSLATION_LAYER.md）を参照する。

### 適用
この規約は、Macro Harnessに参加するすべてのAIエージェントに適用する。
