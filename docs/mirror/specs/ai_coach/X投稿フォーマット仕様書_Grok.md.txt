# X 投稿フォーマット仕様書（Grok 作成）

- 作成：Grok（初版 2026-10-31）。2026-11-01 に NO3 経由で MUSE が机へ格納した。
- 根拠（Grok の整理）：X の「おすすめ（For You）」アルゴリズムの公開コード（home-mixer / param.rs、xai-org/x-algorithm）と 2026年10月の更新、ろじんさん（@fiction_log）の解説・実践知見。
- 扱い：数値は公開コードのデフォルト値に基づく Grok の整理で、本番環境では実験フラグや微調整が入りうる。MUSE は数値そのものを独立には検証していない。Grok の作業仕様として使う。

## 1. 目的

おすすめ（For You）で拡散されやすい投稿の型を定義し、再現性高く「飛ぶ」投稿を量産する。

## 2. アルゴリズムの核心（優先順位の高いシグナル）

スコアは「その行動が起きる予測確率 × 重み」の合計で算出される。実際の発生頻度が低い行動ほど、重みが大きく設定されている傾向がある。

### その他の重要ポイント

- 最初の30分〜2時間のエンゲージメント速度が到達範囲を大きく左右する。
- 弱小アカウント優遇が強化（フォロワー5万未満・新規投稿の初期ブースト）。
- 同一投稿者の連投は減衰。同じ投稿者の2件目以降は減衰し、フォロー外の投稿は概ね0.75倍などの補正が掛かることがある。
- 投稿から48時間程度で候補から外れやすい。
- 記事単体はほぼ流れてこない。引用とセットで配信される傾向が強い。
- 2026年10月の大きな変更：視聴時間（Dwell）の予測精度向上、「フル視聴／最後まで読まれた」概念の追加、いいね重みの微増（0.5 → 0.66）、弱小アカウント・新規投稿への初期ブースト強化。

## 3. 伸びやすい形式ランキング（ろじんさん知見）

引用 ＞ 記事 ＞ 動画 ＞ 画像。最強コンボは「引用 + 記事」または「引用 + 動画」。

## 4. 推奨投稿フォーマット（型）

### 型A：記事＋自引用（フォロワー獲得・拡散の主力）
- 週1本以上、市場の広いテーマで記事を作成。記事公開直後に、自分で短文引用または動画付き引用を投稿する。
- 引用文のポイント：冒頭1行で「読む理由」を提示（数字・意外性・具体性）。「さらに表示」を押したくなる or 動画をタップしたくなる構成。最後まで読ませる／視聴させる設計（読了・滞在時間重視）。

### 型B：短文ポスト（運要素はあるが型で再現性を上げる）
- 1〜3行で完結しつつ、返信を誘発する内容。
- 具体例の型：「〇〇な人の特徴6つ」→ リプ欄で続きを書く（会話誘発）／数字＋意外性（「100人中99人が…」）／問いかけ or 意見が分かれるテーマ。
- 画像・動画を付ける場合は「タップされる」ことを意識（滞在時間計測がしやすくなる）。

### 型C：動画付き引用（現状かなり強い）
- 引用元に記事 or 有益ポストを選び、引用側に動画を付ける。サムネが「タップしたくなる」ことが最重要。動画は最後まで見られる長さ・内容にする。

### 型D：滞在時間・読了重視型（2026年10月更新対応）
- 長文ポスト：「さらに表示」を押させる冒頭。記事：最後まで読まれる構成（導入→価値→具体→結論）。動画：フル視聴されやすい尺と内容。
- 「短い方が有利」という単純な考えは誤り。同じ読了率なら長い方が評価されやすい。

## 5. 最適化戦略

### 最優先で狙うべき行動（重み順）
- リンクコピー共有（20.0）：「保存して誰かに送りたくなる」「メモしたい」情報にする。
- 相互フォローからの返信（20.0）：既存フォロワーと会話が生まれる問いかけ・意見提示。
- 返信・引用・DM共有（各5.0）：返信したくなる余白を残す／引用したくなる切り口にする。
- フォロー（4.0）：「この人の投稿をもっと見たい」と思わせる一貫性と価値。
- 滞在時間・読了・フル視聴（強化中）：最後まで読ませる／見させる構成を徹底。
- いいねや単純リポストは相対的に軽いので、会話と共有を主目標にする。

### 投稿形式の最適化優先順位
引用 + 記事（最強クラス）／引用 + 動画／記事単体（ほぼ流れないので必ず自引用をセット）／動画付きポスト／画像付き・長文テキスト／短文テキスト（運要素が強いが型で再現性を上げる）。
記事運用の鉄則：記事を出したら必ず自分で引用する。引用文は「読む理由」を1行目で明示（数字・意外性・具体性）。記事単体でタイムラインに流れる割合は極めて低い。

### コンテンツ設計の核心原則
1. 冒頭で「読む／見る理由」を提示：数字を入れる（「100人中99人が…」「3日で結果が出た方法」）、意外性・具体性を出す、「さらに表示」を押したくなる or 動画をタップしたくなる書き出し。
2. 滞在時間・読了を最大化：長文は「さらに表示」を押させる構成。記事は 導入 → 価値提示 → 具体例 → 結論 の流れで最後まで読ませる。動画はフル視聴されやすい尺と内容。「短い方が有利」は誤りで、同じ読了率なら長い方が評価されやすい。
3. 返信・引用を誘発する設計：意見が分かれるテーマ、「あなたの場合はどうですか？」系の問い、リスト形式で途中で切る（リプ欄で続き）、引用したくなる切り口。
4. 共有したくなる情報にする：保存価値の高いノウハウ・まとめ、一次情報や独自の視点、「これ知らない人に教えたい」と思わせる内容。

### タイミングと初期ブースト戦略
- 最初の30分〜2時間が勝負。この時間帯のエンゲージメント速度が到達範囲を大きく左右する。自分のフォロワーがアクティブな時間帯に投稿し、投稿直後は返信にすぐ対応して会話を加速させる。
- 弱小アカウントでも初期ブーストが強化されているため、質の高い投稿を継続すれば伸びる余地がある。

### 避けるべきこと（マイナスを最小化）
- 「興味なし」「ミュート」「ブロック」「通報」を招く煽り・低品質・スパム的表現。
- 外部リンクを本文に直接貼りすぎる（必要ならリプ欄へ）。
- 同一内容の連投・コピペ。同じ投稿者の投稿が連続して表示されすぎないよう間隔を空ける。
- クリックベイトだけで中身が薄い投稿（クリック重みは低下傾向）。

### 実践的な運用フロー（推奨）
週1本以上の記事を市場の広いテーマで作成 → 記事公開直後に自引用（短文 or 動画付き）を投稿 → 日常は「返信誘発型の短文」と「有益まとめ」をバランスよく → 投稿後30分〜2時間は積極的に返信対応 → 伸びた投稿の型を記録し、再現性を高める → 定期的に公開コードと最新解説を確認して調整。

## 6. 投稿作成の必須チェックリスト

- [ ] 返信・引用・共有（リンクコピー/DM）を誘発する設計になっているか
- [ ] 冒頭で「読む/見る理由」が明確か（数字・具体・意外性）
- [ ] 滞在時間・読了・フル視聴を意識した長さと構成か
- [ ] 記事を出す場合は必ず自引用をセットで出すか
- [ ] 最初の30分〜2時間で反応が取りやすい時間帯に投稿しているか
- [ ] ネガティブ反応（興味なし等）を招きやすい煽り・低品質表現を避けているか
- [ ] 同一内容の連投・コピペを避けているか
- [ ] 保存・共有したくなる価値があるか

## 7. 運用上の注意

- アルゴリズムは頻繁に更新されるため、公開コードとろじんさん等の最新解説を定期的に確認する。
- 有益情報・1次情報・まとめ直し（再現性重視）が基本。センスに依存しすぎない運用を推奨。

# ジャンル別テンプレート編（Grok 作成）

共通ルール：一次情報（自分がやったこと）をベースにする。数字・期間・結果をできるだけ入れる。読者がすぐ真似できる具体性を優先する。

## 1. ジャンル別・飛ぶ投稿型テンプレート

### A. ビジネス系
型1：数字＋結果提示型
「月商○万円を達成した人が、最初の30日で絶対にやったこと3つ。1. ○○ 2. ○○ 3. ○○。特に3つ目をやらなかった人はほぼ伸びなかった。」

型2：失敗→成功の対比型
「『頑張っても売れない』状態から抜け出した方法。以前：毎日投稿して反応ほぼゼロ／今：1投稿で問い合わせが止まらない。変えたのはこの1点だけ。↓」

型3：リスト切り型（リプ欄で続き）
「売上が伸びない経営者がやりがちなミス7選。1〜3はリプ欄に書きました。残りは引用でまとめます。」

### B. 自己啓発系
型1：特徴リスト型
「本当に成長が早い人の共通点6つ。・すぐ行動する ・感情より事実を見る ・他人の成功を素直に喜べる ・... 残り3つは引用先の記事にまとめました。」

型2：逆説型
「『努力すれば報われる』は半分嘘。報われる努力と、報われない努力の違いはこれです。」

型3：問いかけ＋余白型
「あなたは『忙しい』を言い訳にしていませんか？本当に結果を出す人は、忙しい中でもこれを優先しています。」

### C. AI系
型1：時短・効率化型
「ChatGPTを『ただの検索』で終わらせてる人、もったいない。プロンプトをこう変えるだけで、作業時間が1/3になりました。具体例を記事にまとめました↓」

型2：比較・検証型
「GrokとClaude、実際に同じ仕事をさせた結果。文章作成：○○が圧勝／データ整理：○○が強い／アイデア出し：ほぼ互角。使い分けの基準をまとめました。」

型3：未来予測＋具体策型
「2026年後半、AIを使いこなせない人は確実に置いていかれる。今から始めるならこの3ステップだけで十分です。」

### D. 美容系
型1：ビフォーアフター暗示型
「肌荒れが止まらなかった私が、3週間で変化した方法。やったことはシンプルで、・○○をやめた ・○○を追加した ・○○の順番を変えた。詳細は引用先に書きました。」

型2：悩み共感→解決型
「『高い化粧品を使っても効果が出ない』人へ。実は成分より大事なのは○○です。これ知らないとどれだけお金をかけても変わりません。」

型3：ランキング・厳選型
「敏感肌の私が本当に使ってよかったスキンケア3選。1位は予想外の○○でした。理由と使い方を記事にまとめました。」

## 2. 引用記事の具体的な構成例（最強コンボ）

記事を書いたら必ず自分で引用するのが基本。引用ポストの基本構成（推奨）：
数字 or 意外性 or 強い結論でフック
記事を読む理由を簡潔に提示
「詳細はこちら」「続きは記事で」など誘導

具体例1：ビジネス記事の引用
記事タイトル例「月商100万を超えた個人事業主が最初の90日でやったこと」
引用ポスト例「月商30万で止まっていた人が、90日で100万を超えた方法。特別な才能も資金もありませんでした。変えたのは『やることの順番』だけです。具体的なステップを記事にまとめました。」

具体例2：自己啓発記事の引用
「成長が遅い人と早い人の決定的な違い、ようやく言語化できました。努力の量ではなく『○○の質』が全てでした。記事で詳しく解説しています。」

具体例3：AI記事の引用
「AIを使っても作業が早くならない人の共通点。プロンプトが悪いのではなく、使い方の設計が間違っています。正しい設計を記事にまとめました。」

具体例4：美容記事の引用
「『高い化粧水を使っても肌が変わらない』原因、これでした。成分より大事な順番とタイミングがあります。敏感肌の私が実践して効果が出た方法を書きました。」

引用をさらに強くするオプション：動画を付ける（サムネがタップしたくなるもの）／「リプ欄に補足を書く」と予告して返信を誘発／数字を必ず入れる（「3つの方法」「7つの特徴」「90日で」など）。

## 3. すぐに使える汎用テンプレート集

テンプレート①（数字フック）
「を達成した人が、例外なくやっていたこと。1. 2. 3. 特に重要なのは○番目です。」

テンプレート②（逆説フック）
「『○○すれば成功する』は半分間違いです。本当に結果が出る人は、○○ではなく○○を優先しています。」

テンプレート③（共感→解決）
「『頑張っているのに結果が出ない』と感じている人へ。原因は努力不足ではなく、○○にあります。ここを変えるだけで動き出します。」

テンプレート④（リスト切り）
「○○な人の特徴7つ。1〜4はここに書きました。残り3つは引用先の記事で解説しています。」

テンプレート⑤（記事引用専用）
「○○は○○で決まる。理由と具体的なやり方を記事にまとめました。読むだけで明日から使える内容です。」

## 4. 追加ジャンル（記事本文の構成例＋動画付き引用の台本例）

### 投資系
特徴：「実際にいくら入れて、何ヶ月でどうなったか」を必ず書く。勝った話も負けた話も両方入れると信頼性が上がる。
記事本文の構成例：導入（結果を先に出す）「2025年1月からNISAで毎月3万円積み立てたら、10ヶ月で評価額＋18万円になった話」→ やったこと（具体的な行動：銘柄選定基準、買ったタイミングと金額、使ったツール・アプリ）→ 途中経過（数字の変化を表や箇条書きで月ごとに）→ 失敗・反省点（「ここで焦って売らなくてよかった」など）→ まとめ・今の方針。
動画台本例（15〜30秒想定）：「NISAで毎月3万円、10ヶ月続けたら＋18万円になった。特別なことしてない。ただ『買うタイミング』を1つだけ変えた。詳しくはプロフィールの記事に書いてあるよ。」

### 育児系
特徴：「年齢・状況・具体的なやり方・結果」をセットで書く。感情よりも再現性を重視。
記事本文の構成例：導入（困っていたこと＋結果）「2歳の夜泣きが酷くて毎晩3回起きてたのが、ある方法を始めて2週間でほぼゼロになった」→ 当時の状況（正直に書く：睡眠時間・夫婦の負担・試したこと）→ 実際にやった方法（ステップ形式で番号）→ 変化の過程（日数と変化）→ 注意点・向いてない人 → まとめ。
動画台本例：「2歳の夜泣き、毎晩3回起きてたのが2週間でほぼゼロになった方法。特別なグッズも使ってない。やり方は記事に全部書いたから、同じ悩みの人は見てみて。」

### 副業系
特徴：「本業を続けながら」「初期費用」「時間の使い方」「実際の収入推移」を必ず入れる。
記事本文の構成例：導入（結果）「本業会社員のまま、副業で月5万円を90日で達成した全手順」→ 選んだ副業と理由（なぜその副業にしたか、初期費用）→ 1ヶ月目・2ヶ月目・3ヶ月目の行動と数字 → 時間の作り方（何時から何時までやったか）→ 失敗したこと・やめたこと → 今も続けている理由と次の目標。
動画台本例：「会社員のまま副業で月5万、90日で到達した。初期費用はほぼゼロ。毎日やったことと時間の使い方を全部記事にまとめたよ。」

### マーケティング系
特徴：「施策→数字の変化」をセットで書く。抽象的な理論より「実際に試した結果」を優先。
記事本文の構成例：導入（結果）「メルマガの開封率を18%から41%に上げた、たった1つの変更点」→ 変更前の状態（数字付き）→ 実際に変えたこと（具体的な文章やデザイン）→ 変更後の数字推移 → なぜ効果があったのか（自分なりの分析）→ 他の人でも試せるポイント。
動画台本例：「メルマガ開封率、18%から41%に上がった。変えたのは件名だけじゃない。具体的に何をしたか全部記事に書いたから、興味ある人はチェックして。」

### 追加でよく使えるジャンル（簡潔版）
健康・ダイエット系：構成＝開始時の数値 → やったこと → 週ごとの変化 → 継続のコツ。台本例：「体重あと3kg落ちなくて悩んでたのが、ある習慣を変えたら2週間で落ちた。やり方は記事にまとめた。」
英語・スキル学習系：構成＝開始時のレベル → 毎日のルーティン → 〇ヶ月後の結果 → 失敗した学習法。台本例：「英語ゼロから3ヶ月で日常会話できるようになった勉強法。1日やった時間と使った教材を全部書いた。」
ライフスタイル・習慣系：構成＝以前の状態 → 取り入れた習慣 → 変化したこと → 続けられた理由。台本例：「朝のルーティンを変えたら集中力が明らかに上がった。具体的に何をしたか記事にまとめてある。」
