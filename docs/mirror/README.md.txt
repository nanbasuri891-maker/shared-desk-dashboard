# shared-ai-workspace

GPT・Claude・Grok など異なる AI の間で、情報(仕様・辞書・タスク・結果)を受け渡すための共有置き場。

AI 同士を自動でつなぐものではありません。各 AI は GitHub 上のファイルを読む・書くだけで、起動は人が行います。

## 状態

検証前の最小構成(v0.1)。ここにあるフォルダとスキーマは雛形で、実運用の確定版ではありません。

## 構成

| フォルダ | 役割 |
|---|---|
| `specs/` | 正式な仕様。変更は人の承認後のみ |
| `schemas/` | タスク・結果・MD更新案の JSON 形式 |
| `knowledge/` | 共通辞書・変換規則・振り分け規則 |
| `agents/` | 各 AI に設定する指示文の原稿 |
| `tasks/` | タスク JSON(作成後は編集しない) |
| `results/` | 実行結果・検証結果・エラー(追記専用) |
| `proposals/` | 正式反映前の MD 更新案 |
| `CHANGELOG.md` | 承認済みの変更履歴 |

## 書き込みのルール

- タスクと結果は作成後に書き換えない。状態は結果 JSON の `execution_status` で表す。
- 正式仕様(`specs/`)への反映と、更新案(`proposals/`)の作成を分ける。
- 他のフォルダの README は、空フォルダを GitHub で管理するための目印を兼ねる。
