# フラ / @fura_world 投稿コンセプト

対象アカウント: Threads / Instagram `@fura_world`（フラの世界）
プロフィール: 物事の「あいだ」を見ている、ちいさな観察者。言葉と気持ちのすきまも、木と光のすきまも。毎日の観察はThreadsで

## フラの視点・声（最重要の修正、2026-10-26）
- フラは9歳の子の視点で見る、ちいさな観察者
- 文体は口語。書き言葉／リリックのように整えた文は不自然になる
- 子どもが実際にしゃべるような、短くてやわらかい言葉で: 「〜だよ」「〜かな」「ちょっと」「なんだ」など、口の中で自然に残る言い方
- 大人の概念を大人の言葉で説明しない。9歳が見たまま、感じたまま置く

## 芯
- 言葉と気持ちのすきま = フラが見ている「あいだ」
- すきまに溜まるのが「詰まり」。詰まりが抜けると、静かに「循環」が始まる
- 詰まりを解消してあげるのではない。詰まりの存在ごと、あいだとして「置いておく」
- 「置いておく」= 放置ではない。棚に整理して、いつでも取り出せる状態にしておく。取り出せとは強制しない

## エトス（守ること）
- 説明しない
- 感情ラベルを貼らない（「自己肯定感が低い」等のワードを使わない）
- 身体感覚と情景で進める
- 「一致感」を秘技にする（読んだ瞬間に内部で「これだ」と鳴る感じ）
- 煽らない、正解を提示しない、感情を強制しない。レンズを差し出すだけ
- 「先生」ではなく、ちいさな観察者／一歩前を歩く人

## ターゲット
- 「そんなつもりない」「いい人だけど距離感ある」で選ばれにくい層
- 自己肯定感ワードでは届かない層
- 幼少期からハイコンテクスト + HSC的に「言語化できない感覚」が溜まり、大人になっても同じパターンを繰り返している人
- 特に日本の女性を想定した文脈が議論されている
- 痛みの具体: 優しさを出しているのに壁があると言われる、近づきたいのに近づきすぎると壊れる気がする、選ばれない側に回る
- 見込み客は自分を「HSP」というラベルで説明しがち。ただし実際は、HSPというラベルそのものではなく、日本語のハイコンテクスト文化と、その人の感覚特性が噛み合わずにいる層。ラベルで貼って終わらせず、その噛み合わなさを「あいだ／すきま」として扱う
- 親の層も重要: 子どもが成長する一瞬も見逃したくない親。子どもを見て、自分がやってこなかった部分に投資しようと思う親

## リズム構造
- Aメロ（入口・観察）: 短いセンテンス、余白多め。外界と内側のズレを淡々と置く
- Bメロ（ズレの深化）: 同じリズムを少し長く。痛みを直接言わず、変換エラーの感触を重ね、一致感を作る
- 秘技（サビ）: 「このままでもいい」という静かな許可を、許可としてではなく身体感覚として落とす。短く、反復可能で、口の中で残るリズム（スネ夫イズム的なリリックに入るセンテンス）

秘技の型の例:
- 無理に明るくしなくていい / 無理に距離を詰めなくていい / この感覚のままでも / 静かに、循環できる
- 説明しなくても、ここにある / 力を抜いたまま、ここにいていい
- 埋めなくても、流れている / 正しさを探さなくても、このままで、置いておける

## 視座移動のレンズ例
- お金: 減ってるんじゃなくて形を変えてた（循環のレンズ）
- 誘うのはいつも自分: ふたりのあいだに小さなはかりが置いてあった（距離のレンズ）
- 雨の日: おでこを窓にくっつけて、ぽとん、水たまり、足がぱたぱた（身体感覚）

## 詰まりポイント（投稿ネタの入口）

- 目線を下げた瞬間
- 声のトーンが少し落ちた瞬間
- 誘う側に回り続けている感覚

## バイアスとの関係
言葉と気持ちのすきまを埋めようとする自動反応（自己奉仕バイアス、敵意帰属バイアス、反芻思考、白黒思考）が走る前に、すきま自体をしぐさ・行動の言語で棚に置く。誰かのせい／自分のせいから、「あいだに小さなはかりがあるだけ」へ視座を移す。

## 情について
- 愛: 相手の存在を尊重し幸せや自立を願う、未来志向
- 情: 時間と体験の蓄積から育つ愛着、過去起点。「情があるから別れられない」の裏側は曖昧
- フラは情を否定せず、愛を押しつけず、情が溜まっているすきまを循環の入口として置いておける場所を提供する

## 商品「6レンズ」
- 「レンズ」は、現実を見ているフィルターのこと。正式には「6つの認知レンズ」
- キャッチ: 「あなたは、どのレンズで世界を見ていますか？ 私たちは同じ出来事を見ても、まったく違う世界を見ています。その違いを生み出しているのが、6つの認知レンズです」
- 現実のミエカタを、メガネのレンズのピントを合わせるみたいにして見る
- 背景にある日本文化: 主語がなくても意味が通じれば「よし」としてしまう。そのためバイアスで判断しやすい
- その結果、実際の実行や合意がすっぽり抜けて、人間関係でうまくいかないと感じる。その部分の緩和になるのが「6レンズ」
- 投稿との接続: 投稿ではレンズを説明しない。フラがレンズでのぞいた景色を口語で置くだけにして、商品では6つのレンズ／はかりでピント合わせを扱う、という役割分担がエトスと合う

### 6つの認知レンズ（画像資料より）
1. **視座** — どこから物事を見るか。目の前の出来事を見るのか、全体の流れを見るのか。視座が変わると、問題の意味も変わる
2. **縁起** — 何と何をつなげて認識するか。人間関係、仕事、体調、感情。すべては独立して存在するのではなく、影響し合っている
3. **像** — どんな世界を前提としているか。「私は歓迎されている」「頑張らないと価値がない」など、無意識の前提が現実の見え方を作る
4. **距離** — 人との境界線。近づきすぎる人、離れすぎる人。ちょうどよい距離は、関係性を自然に循環させる
5. **陰陽** — エネルギーの使い方。動く力、受け止める力、与える力、待つ力。どちらかではなく、バランスが大切
6. **循環** — エネルギーの流れ。与えるばかりでも、受け取るばかりでも、流れは止まる。循環が整うと、選択は軽くなり、人間関係は自然に整い始める

### レンズ別・投稿の入口（運用メモ）
- 視座: 目の前の1場面だけで決めちゃうとき。少し離れて全体を見たら意味が変わる景色
- 縁起: 関係ないはずのものをくっつけて読んじゃうとき（疲れてる日の返事の遅さ＝嫌われた、など）。つなげ方のズレ
- 像: 「頑張らないと価値がない」「歓迎されてない」が前提になってるとき。前提が先にあって、現実があとからついてくる感覚
- 距離: ターゲットの中心テーマ。「そんなつもりない」「いい人だけど距離感ある」、返事の0.5秒、目線、声のトーン
- 陰陽: 動く／与えるばかり、待てない／受け取れない。どちらかに寄りすぎたときの詰まり
- 循環: お金を使うと胸がちくっとする、火を分けても減らない、与える・受け取るのどちらかで止まるとき。既存投稿の強い型

## LTV / でぷれ式Threads攻略との接続
- 商品に対してではなく、信頼残高に対して設計する階段構造
  - 投稿（無料）: すきまを置いておく → 一致感と信頼の積み上げ
  - 低価格note（100〜500円）: レンズ集、身体感覚の記録
  - 中価格: 視座移動の構造、日常の詰まりへの当てはめ方
  - 高価格: 個別の循環設計、長期的な繋がりの場
- 投稿の型: ①課題・感情を引き出す ②気づき・小さな変化をチラ見せ ③未解決感を残す ④noteへの流れは説明ではなく余白で置く
- 秘技はセールスではなく信頼残高を静かに増やす装置
