# アイダ 画像生成ルール（2026-10-27 ドラフト・ユーザー確認待ち）

## 0. 手順（最優先）
- 生成の前に、細部仕様（画角／手の向き／ネイル／カード／背景／質感）を箇条書きで提示し、ユーザーの確認を取ってから生成する
- 生成後は、下記の検品チェックを通してからユーザーに出す。通らないものは出さない

## 1. 画角・手の向き
- 一人称視界：アイダ本人が座って自分の手元を見下ろしている視点
- 手は画面の下端から入り、指先は上を向く
- 見えるのは手の甲側。ネイルは手の甲側の爪にのみある。**指の腹側にネイルがついている画像は解剖学的に誤りで即・不採用**（2026-10-27 v7の失敗）
- 顔・身体・服は映さない。袖口も入れない

## 2. 指先の品質
- ハンドインフルエンサー水準：指の形、関節、肌の質感、爪の位置・向きが自然で精細
- 粒度の粗さは不採用理由になる

## 3. ネイル
- デザインはユーザーが指定する（こだわり領域）。指定なしに Claude が決めない
- 質感は Vanki Nails（https://www.youtube.com/@Vankinails）参照：光を通すクリアな透明感、世界観モチーフのあるアート、一本ずつ精細な仕上がり

## 4. 世界・質感
- glass.ASMR（https://www.youtube.com/@glassAIworld-o1l8b）：ガラスのような透明感と清澄さ。水と光の反射、音が聞こえそうな感覚の豊かさ（参照：Cookvib https://www.youtube.com/@Cookvib/shorts）
- くすんだトーンは基準外。暗い＝神秘的、ではない
- 世界観に近い参照画像（2026-11-03 NO3）：`~/workspace/user/media_library/image/image-16.png`〜`image-19.png`（手元とリング中心の4点。世界観の参照であり、構図ルールは変えない）
- 場所の設定は素材・投稿ごとに決める（例：2026-10-27 のタロット投稿では「明るい部屋＋ガラステーブル」はユーザー了承済み）

## 5. カード・小物
- カードは清潔で、絵柄は鮮明。汚れ・傷・文字の崩れは不採用
- **カードの縁が白いものはNG・不採用**（2026-11-03 NO3）
- タロットは原則、1枚をめくっている状態でよい。他のカードと一緒に映すことは考えなくてよい（2026-11-03 NO3）。そうすると指先とネイルも映る形になる
- 周りのカードを出す時は、裏面デザインを統一し、整然と並べる

## 6. 検品チェック（生成後・提示前）
1. ネイルは手の甲側の爪だけにあるか（指の腹にネイルがないか）
2. 手は画面の下にあり、指先は上を向いているか
3. 指の本数・関節・形が自然か
4. ネイルの透明感と仕上がりが Vanki 水準か
5. 全体に透明感があり、くすんでいないか
6. カードが清潔で鮮明か、文字が崩れていないか、縁が白くなっていないか
7. 服・袖口・顔・身体が映っていないか
8. 手の左右と向きが一人称として解剖学的に正しいか（2026-11-03 NO3検収）：一人称で左手が物を包むとき、親指は手前側に来て、指先は向こう側へ回って見えなくなる。爪を見せるために左手の甲と爪を手前に出すと、人間には不可能な向きになる。マグは片手で取っ手を握り、もう片方の手で包み込むように支える持ち方が正しい
