# Claude EXECUTION_RULES

## 入口の自己防衛

1. 起動時に読むのは次の3点だけ
   - CLAUDE_START
   - CLAUDE_STATE
   - 今回の依頼パッケージ
2. CLAUDE_STATE が800字を超えていたら作業しない。「STATEが上限超過。瘦せてから出直して」と返して終了する
3. CLAUDE_STATE に完了済みなのに「未実行」の行があったら作業しない。「完了行が残っている。削除してから出直して」と返して終了する
4. 上記以外のファイルをポインタで辿って開かない
5. 自分で STATE を整形・削除しない。拒否してMUSEに戻す
