1. 核となる思想：「美しいバズ」vs「美しくないバズ」

  • 美しくないバズ：一時的な話題・再生数増だけで終わり、売上や問い合わせにつながらないもの（炎上や無関係層の流入を含む）。
  • 美しいバズ：明確なゴール（誰に・何を・どんな未来を届けるか）から逆算し、認知 → ファン化 → 集客 → 信頼構築 → 販売 → リピートまで一直線につながるもの。

最終目標は「営業しなくても売れる状態」の構築。再生数やフォロワー数は手段であり、ゴールではないと繰り返し強調しています。

2. 7つのプロセス（全体設計図）

著書で提示するフレームワークです。

  1. コンセプト設計
    「誰に・何を・どんな未来を」を最初に明確化。ペルソナの悩みを100個以上言語化するなど、解像度を極限まで高める。ここが曖昧だと後が全部崩れる。

  2. 認知
    YouTube長尺、Shorts、TikTok、Instagramで未認知層に届ける。媒体ごとに戦略を変える。

  3. ファン化
    一度の視聴者を「この人から買いたい」層に変える。値引き不要の状態を作る。

  4. 集客
    SNSから自社フィールド（LINE、メルマガ、LPなど）へ誘導。

  5. 信頼構築
    実績・お客様の声・一貫した発信で不安を取り除く。

  6. 販売
    売り込まず「求められて売る」。

  7. リピート
    LTV最大化。

この流れを「点」ではなく「線」で設計するのが特徴です。

彼が最も強調するポイントです。YouTubeの新規獲得経路を以下の5つに分け、それぞれで「狙う企画」を変えます。

  • ブラウジング流入（ホーム画面・登録チャンネルフィードなど）

  • 外部流入

これに「ファン化狙い企画」と「コンバージョン狙い企画」を加え、最低7パターンの企画戦略を使い分けるのが「YouTubeマスター」の基準だと明言しています。

2. コンテンツの4分類と出す順番

再生数やフォロワーが増えても売上に繋がらない人への指摘として、以下の4パターンを明確に分類して運用することを推奨しています。

  1. ファン化のための自分を深く知ってもらうコンテンツ（再生数は期待しない）
  2. ファン化へのガチ有益コンテンツ（YouTube SEOを意識、ジワ伸び狙い）
  3. 再生数を取るための認知コンテンツ（ここで初めてimpを取りにいく）
  4. コンバージョンのためのコンテンツ

順番を間違えると「認知だけ取ってマネタイズできない」状態になると指摘。最初に1・2をしっかり置き、その後に3で集めた視聴者を1・2に流し、最後に4で成約させる設計を推奨しています。

彼が繰り返し強調する「多段階ペルソナ構造」は、単なる「初心者〜上級者」の分け方ではありません。

2. 長尺起点の自社メディア戦略（切り抜き → 各SNS展開）

彼のメディア設計は明確に「長尺が本体」です。

  • 長尺動画：ファン化・信頼構築・SEO資産・ドキュメンタリーによるCVR向上の本丸
  • ショート切り抜き：長尺から抽出した「フックの強い部分」を各SNS（YouTube Shorts、TikTok、Instagram）に展開
  • 目的：長尺で深い関係性を作り、ショートでマス認知と新規流入を加速させる

この構造により、 1. 長尺で濃いファンと高LTV顧客を育てる 2. ショートで認知を広げ、長尺へ回遊させる 3. 各SNSのアルゴリズム特性に合わせて最適化する

という循環が生まれます。単発のバズを狙うのではなく、自社メディア全体を資産として積み上げる設計です。
